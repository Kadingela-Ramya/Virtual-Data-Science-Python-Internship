# Week 1: Data Acquisition, Cleaning and Exploratory Data Analysis

## Dataset

Netflix Movies and TV Shows Dataset

## Objective

The objective of this project is to perform data acquisition, data cleaning, preprocessing, and exploratory data analysis using Python.

## Tasks Performed

* Data acquisition
* Dataset exploration
* Missing value analysis and handling
* Duplicate checking and removal
* Data type conversion
* Exploratory data analysis
* Data visualization

## Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Google Colab

## Files

* `Netflix_EDA.ipynb` — Complete Python code and analysis
* `netflix_titles.csv` — Dataset used for the project
* `Week1_Netflix_EDA_Report.docx` — Project report
